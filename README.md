# FF Gamecoin

Free Fire Topup and gaming recharge web application rewritten as a modern React SPA using Vite, TypeScript, and Tailwind CSS.

## Features
- **Promotional Carousel**: 4-second auto-cycling hero banners with touch drag and swipe support.
- **Top-up Categories**:
  - FF Likes
  - UID Topup (BD)
  - Weekly / Monthly
  - Weekly Lite
  - Level Up Pass
  - Indonesia Server
- **Free Fire UID Checker**: Live validation and player name retrieval via API.
- **Payment Options**: Instant Pay and Wallet Pay with real-time balance calculations.
- **Add Money Flow**: bKash, Nagad, and Rocket integration with step-by-step Bengali instructions, personal send money number, and transaction ID verification.
- **My Orders & My Codes**: Live order management and voucher redemption tracking.
- **User Authentication**: Support for guest mode, registration, login, and profile tracking.
